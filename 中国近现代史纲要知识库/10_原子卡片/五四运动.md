# 五四运动

## 一句话定义

一场彻底反帝反封建的爱国运动，是中国**旧民主主义革命走向新民主主义革命的转折点**，标志着中国新民主主义革命的开端。

## 核心内容

### 四大意义

1. **转折点、里程碑**
   - 以彻底反帝反封建的革命性、追求救国强国真理的进步性、各族各界群众积极参与的广泛性，推动了中国社会进步
   - 促进了马克思主义在中国的传播，促进了马克思主义同中国工人运动的结合
   - 为中国共产党的成立做了**思想上干部上的准备**，为新的革命力量、革命文化、革命斗争登上历史舞台创造了条件
   - 因此成为中国新民主主义革命的开端
2. **五四精神**：孕育了以爱国、进步、民主、科学为主要内容的伟大五四精神，其**核心是爱国主义**
3. **第一次全面觉醒**：改变了以往只有觉悟的革命者而缺少觉醒的人民大众的斗争状况，实现了中国人民和中华民族自**鸦片战争以来**的第一次全面觉醒
4. **永久奋斗传统**：以全民族的搏击培育了永久奋斗的伟大传统，标志着**中国青年成为推动中国社会变革的急先锋**

### 辨析：马克思主义的传播是中断还是深化了新文化运动的思想启蒙？

**结论：深化，不是中断。**

- 先进分子在接受马克思主义之后，并没有抛弃而是继承了五四运动的科学和民主精神，并赋予它们新的含义，使它们在更高层次上得到发扬
- **民主内涵变化**：五四前是资产阶级民主主义制度和思想；五四后把少数人的民主与多数人的民主、资产阶级的民主与劳动阶级的民主区分开来，提到更高级的层次，扩展到更广泛的范围
- **科学内涵变化**：五四前指自然科学和看待客观事物的科学观点；五四后提倡用马克思主义的观点观察和研究社会，使科学方法的运用从自然界扩展到人类社会、历史研究领域
- **反封建启蒙没有被取消**：马克思主义传播克服了以往启蒙者的弱点，有力推动了反封建的启蒙运动
  - 反封建思想的武器：进化论 → 唯物史观；反封建思想 → 反封建制度
  - 立足点：个人 → 人民群众；个性解放 → 社会解放
  - 斗争方式：少数人 → 人民群众；思想批判 → 革命实践

## 意义 / 评价

- 五四运动是中国新民主主义革命的开端，在近代以来中华民族追求民族独立和发展进步的历史进程中具有里程碑意义
- 它既是爱国运动，也推动了反封建的思想启蒙，为马克思主义传播和中国共产党诞生准备了条件

## 易错点

- “转折点”指**旧民主主义革命 → 新民主主义革命**，不能说五四运动是“旧民主主义革命的开端”
- 五四精神的**核心是爱国主义**，民主与科学是主要内容之一，不能把“核心”答成“民主科学”
- 五四运动为中国共产党的成立做了思想上干部上的准备，但五四运动本身不等于中共成立，两者不能混为一谈
